# Pairing Codes and Per-Machine Tokens 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 删除共享 machine token 和 TOFU，实现「配对码 → 首次 Ed25519 pin → 每机器长期 token」的同机/同内网 onboarding。

**架构：** 配对码在 `connection.hello` 中提交，admin 在 challenge 签名验证通过后原子消费配对码、pin 公钥、登记组织并返回 `afm_...` per-machine token；后续连接用该 token + Ed25519 challenge 认证。token 存在 daemon 的 `<key_file>.token`（0600）。

**技术栈：** Rust workspace、axum、tokio-tungstenite、sqlx/SQLite、Ed25519（ed25519-dalek）、clap、toml_edit。

**规格：** `docs/superpowers/specs/2026-11-16-pairing-design.md`

## 全局约束

- 产品未上线：**不保留**共享 token、TOFU、key-only 兼容路径。
- 只实现同机 / 同内网：admin 必须可达；远程/离线/延迟配对不做。
- 配对码：12 字符 Crockford Base32（`0123456789ABCDEFGHJKMNPQRSTVWXYZ`），展示 `XXXX-XXXX-XXXX`，约 60 bit。
- 配对码 TTL 600 秒，单次使用，最多 5 次尝试；只存 SHA-256 哈希。
- per-machine token 格式 `afm_<64 hex>`，只存 SHA-256 哈希；明文只在 `connection.accepted` 返回一次。
- token 文件：`<key_file>.token`，Unix mode 0600；group/world 可读必须拒绝。
- 所有秘密不得出现在日志：`HelloPayload.pairing_code`、`ConnectionAccepted.machine_token`、`PairingCodeResponse.code` 使用手写 `Debug` redaction。
- 所有非配对连接必须带有效 per-machine token；无 token 无 code：已 pin → `machine_token_required`，未 pin → `machine_not_paired`。
- Rust 代码遵循仓库现有风格；提交信息使用 Conventional Commits。

## 实现细化（规格未写死、本计划采用的细节）

1. **DTO 位置：** `PairingCodeInfo`、`PairingCodeStatus`、`PairingCompletion`、`PairingOutcome`、`MachineAuthState` 放在 `fleet-core-protocol`，避免 `core-connection` 依赖 `admin-storage` 造成循环。`ConsumedCode` 留在 `admin-storage`。
2. **`ConnectionAccepted` 增加可选 `org_id`：** 配对成功后 daemon 可报告组织；非配对连接为 `None`。
3. **`pair_machine` 增加 previous identity 参数：** 支持 key rotation 后的重新配对。
4. **CLI 使用 `--daemon-config`：** 全局 `--config` 已被 CLI 自身配置占用，避免冲突。
5. **per-IP 限流用 `PeerAddr` extractor：** 没有 `ConnectInfo` 的测试自动跳过限流。

```rust
//! Pairing-code and per-machine-token generation.

use rand::rngs::OsRng;
use rand::RngCore;
use sha2::{Digest, Sha256};

/// Number of symbols in a normalized pairing code.
pub const PAIR_CODE_LEN: usize = 12;

/// Crockford Base32: no I, L, O or U.
const ALPHABET: &[u8; 32] = b"0123456789ABCDEFGHJKMNPQRSTVWXYZ";

/// Generate a display code such as `7Q2M-9XKR-4TWD`.
pub fn generate_pair_code() -> String {
    let mut bytes = [0u8; PAIR_CODE_LEN];
    OsRng.fill_bytes(&mut bytes);
    let raw: String = bytes
        .iter()
        .map(|byte| ALPHABET[usize::from(*byte) % ALPHABET.len()] as char)
        .collect();
    format!("{}-{}-{}", &raw[0..4], &raw[4..8], &raw[8..12])
}

/// Normalize user input: uppercase, strip separators, map I/L to 1 and O to 0.
pub fn normalize_pair_code(input: &str) -> Option<String> {
    let mut normalized = String::with_capacity(PAIR_CODE_LEN);
    for ch in input.chars() {
        let ch = ch.to_ascii_uppercase();
        let mapped = match ch {
            'I' | 'L' => '1',
            'O' => '0',
            '-' | ' ' | '\t' => continue,
            other => other,
        };
        if !ALPHABET.contains(&(mapped as u8)) {
            return None;
        }
        normalized.push(mapped);
    }
    (normalized.len() == PAIR_CODE_LEN).then_some(normalized)
}

/// SHA-256 of the normalized code, hex encoded.
pub fn hash_pair_code(input: &str) -> Option<String> {
    let normalized = normalize_pair_code(input)?;
    Some(hex::encode(Sha256::digest(normalized.as_bytes())))
}

/// Generate an `afm_<64 hex>` per-machine token.
pub fn generate_machine_token() -> String {
    let mut bytes = [0u8; 32];
    OsRng.fill_bytes(&mut bytes);
    format!("afm_{}", hex::encode(bytes))
}
```

```rust
//! Per-machine token and stable machine-id files stored next to the key.

use std::fs;
use std::io::Write;
use std::path::{Path, PathBuf};

use crate::error::{AuthError, Result};
use crate::identity::{check_permissions, MachineIdentity};

fn with_suffix(path: &Path, suffix: &str) -> PathBuf {
    let mut value = path.as_os_str().to_os_string();
    value.push(suffix);
    PathBuf::from(value)
}

/// `<key_file>.token`
pub fn machine_token_path(key_file: &Path) -> PathBuf {
    with_suffix(key_file, ".token")
}

/// `<key_file>.id`
pub fn machine_id_path(key_file: &Path) -> PathBuf {
    with_suffix(key_file, ".id")
}

/// Load the per-machine token, rejecting group/world-readable files.
pub fn load_machine_token(path: &Path) -> Result<Option<String>> {
    if !path.exists() {
        return Ok(None);
    }
    #[cfg(unix)]
    check_permissions(path)?;

    let raw = fs::read_to_string(path).map_err(|err| AuthError::io(path, err))?;
    let token = raw.trim();
    if token.is_empty() {
        Ok(None)
    } else {
        Ok(Some(token.to_string()))
    }
}

/// Write the token with mode 0600 and a trailing newline.
pub fn save_machine_token(path: &Path, token: &str) -> Result<()> {
    write_private(path, format!("{}\n", token.trim()).as_bytes())
}

/// Remove the token file if it exists.
pub fn clear_machine_token(path: &Path) -> Result<()> {
    match fs::remove_file(path) {
        Ok(()) => Ok(()),
        Err(err) if err.kind() == std::io::ErrorKind::NotFound => Ok(()),
        Err(err) => Err(AuthError::io(path, err)),
    }
}

/// Read `<key_file>.id`, creating it from the key fingerprint when absent.
pub fn load_or_create_machine_id(
    key_file: &Path,
    identity: &MachineIdentity,
) -> Result<String> {
    let path = machine_id_path(key_file);
    if path.exists() {
        let value = fs::read_to_string(&path).map_err(|err| AuthError::io(&path, err))?;
        let value = value.trim();
        if !value.is_empty() {
            return Ok(value.to_string());
        }
    }
    let value = identity.fingerprint();
    write_private(&path, format!("{value}\n").as_bytes())?;
    Ok(value)
}

fn write_private(path: &Path, bytes: &[u8]) -> Result<()> {
    if let Some(parent) = path.parent() {
        if !parent.as_os_str().is_empty() {
            fs::create_dir_all(parent).map_err(|err| AuthError::io(parent, err))?;
        }
    }

    let mut options = fs::OpenOptions::new();
    options.write(true).create(true).truncate(true);
    #[cfg(unix)]
    {
        use std::os::unix::fs::OpenOptionsExt;
        options.mode(0o600);
    }

    let mut handle = options.open(path).map_err(|err| AuthError::io(path, err))?;
    handle
        .write_all(bytes)
        .map_err(|err| AuthError::io(path, err))?;
    handle.flush().map_err(|err| AuthError::io(path, err))?;

    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        fs::set_permissions(path, fs::Permissions::from_mode(0o600))
            .map_err(|err| AuthError::io(path, err))?;
    }
    Ok(())
}
```

```rust
//! Pairing-code storage.

use fleet_core_common::{new_id, now, Timestamp};
use fleet_core_protocol::pairing::{PairingCodeInfo, PairingCodeStatus};
use sqlx::SqlitePool;

use crate::helpers::*;
use crate::Result;

/// Handle for pairing-code queries.
#[derive(Clone)]
pub struct PairingCodes {
    pool: SqlitePool,
}

impl PairingCodes {
    pub(crate) fn new(pool: SqlitePool) -> Self {
        Self { pool }
    }
}

impl PairingCodes {
    /// Insert a code hash and return the new id.
    pub async fn create(
        &self,
        org_id: &str,
        created_by: &str,
        machine_name_hint: Option<&str>,
        expires_at: Timestamp,
        code_hash: &str,
    ) -> Result<String> {
        let id = new_id("pair");
        sqlx::query(
            r#"
            INSERT INTO pairing_codes
                (id, code_hash, org_id, created_by, machine_name_hint, expires_at, created_at)
            VALUES (?1, ?2, ?3, ?4, ?5, ?6, ?7)
            "#,
        )
        .bind(&id)
        .bind(code_hash)
        .bind(org_id)
        .bind(created_by)
        .bind(machine_name_hint)
        .bind(format_ts(expires_at))
        .bind(format_ts(now()))
        .execute(&self.pool)
        .await?;
        Ok(id)
    }

    /// Validate a code hash. Non-`Valid` statuses are never exposed to clients.
    pub async fn lookup(
        &self,
        code_hash: &str,
        max_attempts: u32,
    ) -> Result<PairingCodeStatus> {
        let row: Option<(String, String, String, Option<String>, String, Option<String>, i64)> =
            sqlx::query_as(
                r#"
                SELECT id, org_id, created_by, machine_name_hint,
                       expires_at, used_at, attempts
                FROM pairing_codes
                WHERE code_hash = ?1
                "#,
            )
            .bind(code_hash)
            .fetch_optional(&self.pool)
            .await?;

        let Some((id, org_id, created_by, machine_name_hint, expires_at, used_at, attempts)) =
            row
        else {
            return Ok(PairingCodeStatus::Invalid);
        };

        if used_at.is_some() {
            return Ok(PairingCodeStatus::Used { id, org_id });
        }

        let expires_at = parse_ts(&expires_at);
        if expires_at <= now() {
            return Ok(PairingCodeStatus::Expired { id, org_id });
        }

        let attempts = u32::try_from(attempts).unwrap_or(u32::MAX);
        if attempts >= max_attempts {
            return Ok(PairingCodeStatus::Locked { id, org_id });
        }

        Ok(PairingCodeStatus::Valid(PairingCodeInfo {
            id,
            org_id,
            created_by,
            machine_name_hint,
            expires_at,
            attempts_left: max_attempts - attempts,
        }))
    }

    /// Count a failed signature attempt.
    pub async fn record_failure(&self, id: &str) -> Result<()> {
        sqlx::query("UPDATE pairing_codes SET attempts = attempts + 1 WHERE id = ?1")
            .bind(id)
            .execute(&self.pool)
            .await?;
        Ok(())
    }
}
```

```rust
    /// Atomically consume a pairing code, pin the key and issue a token hash.
    pub async fn complete_pairing(
        &self,
        request: PairingCompletion,
        max_attempts: u32,
    ) -> std::result::Result<PairingOutcome, ApiError> {
        let mut tx = self.pool.begin().await.map_err(internal_error)?;

        let code: Option<(String, String, Option<String>, String, Option<String>, i64)> =
            sqlx::query_as(
                r#"
                SELECT org_id, created_by, machine_name_hint, expires_at, used_at, attempts
                FROM pairing_codes
                WHERE id = ?1
                "#,
            )
            .bind(&request.code_id)
            .fetch_optional(&mut *tx)
            .await
            .map_err(internal_error)?;

        let Some((org_id, created_by, machine_name_hint, expires_at, used_at, attempts)) = code
        else {
            return Err(pairing_invalid());
        };
        if used_at.is_some()
            || parse_ts(&expires_at) <= now()
            || u32::try_from(attempts).unwrap_or(u32::MAX) >= max_attempts
        {
            return Err(pairing_invalid());
        }

        let revoked: Option<(String,)> = sqlx::query_as(
            "SELECT machine_id FROM machine_revocations WHERE machine_id = ?1",
        )
        .bind(&request.machine_id)
        .fetch_optional(&mut *tx)
        .await
        .map_err(internal_error)?;
        if revoked.is_some() {
            return Err(ApiError::new(
                error_codes::FORBIDDEN,
                format!("machine {} is revoked", request.machine_id),
            ));
        }

        let existing: Option<(Option<String>,)> =
            sqlx::query_as("SELECT public_key FROM machines WHERE id = ?1")
                .bind(&request.machine_id)
                .fetch_optional(&mut *tx)
                .await
                .map_err(internal_error)?;

        if let Some((Some(pinned),)) = existing.as_ref() {
            if pinned != &request.public_key && !request.rotation_verified {
                return Err(ApiError::new(
                    error_codes::MACHINE_KEY_MISMATCH,
                    "machine is already paired with a different key",
                ));
            }
        }

        let existing_org: Option<(String,)> =
            sqlx::query_as("SELECT org_id FROM machine_orgs WHERE machine_id = ?1")
                .bind(&request.machine_id)
                .fetch_optional(&mut *tx)
                .await
                .map_err(internal_error)?;
        if let Some((existing_org,)) = existing_org.as_ref() {
            if existing_org != &org_id {
                return Err(ApiError::new(
                    error_codes::MACHINE_ORG_MISMATCH,
                    "machine belongs to another organization",
                ));
            }
        }

        let consumed = sqlx::query(
            r#"
            UPDATE pairing_codes
            SET used_at = ?1, used_by_machine_id = ?2
            WHERE id = ?3 AND used_at IS NULL
            "#,
        )
        .bind(format_ts(now()))
        .bind(&request.machine_id)
        .bind(&request.code_id)
        .execute(&mut *tx)
        .await
        .map_err(internal_error)?;
        if consumed.rows_affected() != 1 {
            return Err(pairing_invalid());
        }

        let timestamp = now();
        let name = machine_name_hint.unwrap_or_else(|| request.machine_name.clone());

        if existing.is_some() {
            sqlx::query(
                r#"
                UPDATE machines
                SET name = ?2, hostname = ?3, os = ?4, arch = ?5,
                    daemon_version = ?6, protocol_version = ?7, public_key = ?8,
                    token_hash = ?9, token_created_at = ?10,
                    paired_at = ?11, paired_by = ?12, updated_at = ?13
                WHERE id = ?1
                "#,
            )
            .bind(&request.machine_id)
            .bind(&name)
            .bind(&request.hostname)
            .bind(&request.os)
            .bind(&request.arch)
            .bind(&request.daemon_version)
            .bind(i64::from(request.protocol_version))
            .bind(&request.public_key)
            .bind(&request.token_hash)
            .bind(format_ts(timestamp))
            .bind(format_ts(timestamp))
            .bind(&created_by)
            .bind(format_ts(timestamp))
            .execute(&mut *tx)
            .await
            .map_err(internal_error)?;
        } else {
            sqlx::query(
                r#"
                INSERT INTO machines (
                    id, name, hostname, os, arch, daemon_version, protocol_version,
                    status, public_key, providers_json, workspaces_json,
                    created_at, updated_at, token_hash, token_created_at,
                    paired_at, paired_by
                ) VALUES (
                    ?1, ?2, ?3, ?4, ?5, ?6, ?7, 'offline', ?8, '[]', '[]',
                    ?9, ?10, ?11, ?12, ?13, ?14
                )
                "#,
            )
            .bind(&request.machine_id)
            .bind(&name)
            .bind(&request.hostname)
            .bind(&request.os)
            .bind(&request.arch)
            .bind(&request.daemon_version)
            .bind(i64::from(request.protocol_version))
            .bind(&request.public_key)
            .bind(format_ts(timestamp))
            .bind(format_ts(timestamp))
            .bind(&request.token_hash)
            .bind(format_ts(timestamp))
            .bind(format_ts(timestamp))
            .bind(&created_by)
            .execute(&mut *tx)
            .await
            .map_err(internal_error)?;
        }

        sqlx::query(
            r#"
            INSERT INTO machine_orgs (machine_id, org_id, created_at)
            VALUES (?1, ?2, ?3)
            ON CONFLICT(machine_id) DO UPDATE SET org_id = excluded.org_id

            paired_at: timestamp,
```

```rust
struct UpgradeLimiter {
    hits: dashmap::DashMap<std::net::IpAddr, std::collections::VecDeque<std::time::Instant>>,
}

impl UpgradeLimiter {
    fn allow(&self, ip: std::net::IpAddr) -> bool {
        const WINDOW: Duration = Duration::from_secs(600);
        const LIMIT: usize = 30;
        let now = std::time::Instant::now();
        let mut entry = self.hits.entry(ip).or_default();
        while entry.front().is_some_and(|at| now.duration_since(*at) > WINDOW) {
            entry.pop_front();
        }
        if entry.len() >= LIMIT {
            return false;
        }
        entry.push_back(now);
        true
    }
}
```

```rust
/// One-shot pairing handshake. Does not start heartbeat or reconnect tasks.
pub async fn pair_machine(
    config: PairingConfig,
    identity: &MachineIdentity,
    previous: Option<&MachineIdentity>,
) -> Result<PairingResult> {
    let mut request = config
        .server_url
        .as_str()
        .into_client_request()
        .map_err(|err| GatewayError::Http(err.to_string()))?;
    request.headers_mut().remove("Authorization");

    let (socket, _) = tokio::time::timeout(
        config.handshake_timeout,
        tokio_tungstenite::connect_async(request),
    )
    .await
    .map_err(|_| GatewayError::Timeout("pairing connect timed out".into()))??;
    let (mut sink, mut stream) = socket.split();

    let hello = HelloPayload {
        machine_id: config.machine_id.clone(),
        name: config.machine_name.clone(),
        hostname: config.hostname.clone(),
        os: config.os.clone(),
        arch: config.arch.clone(),
        daemon_version: config.daemon_version.clone(),
        protocol_version: config.protocol_version,
        public_key: identity.public_key_base64(),
        pairing_code: Some(config.pairing_code.clone()),
    };
    sink.send(Message::Text(
        ConnectionEnvelope::request(
            methods::HELLO,
            serde_json::to_value(&hello).map_err(GatewayError::from)?,
        )
        .to_json()
        .into(),
    ))
    .await?;

    let challenge_env = read_envelope(&mut stream, config.handshake_timeout).await?;
    if challenge_env.message_type == MessageType::Error {
        let error = serde_json::from_value::<ApiError>(challenge_env.payload)
            .unwrap_or_else(|_| ApiError::new(error_codes::PAIRING_CODE_INVALID, "pairing failed"));
        return Err(error.into());
    }
    let challenge: AuthChallenge =
        serde_json::from_value(challenge_env.payload).map_err(GatewayError::from)?;
    let nonce = base64::Engine::decode(
        &base64::engine::general_purpose::STANDARD,
        &challenge.nonce,
    )
    .map_err(|err| GatewayError::Auth(format!("invalid challenge nonce: {err}")))?;

    let rotation = previous.map(|previous| {
        let statement = key_rotation_statement(
            &config.machine_id,
            &identity.public_key_base64(),
            &challenge.nonce,
        );
        KeyRotationProof {
            new_public_key: identity.public_key_base64(),
            old_signature: previous.sign(statement.as_bytes()),
        }
    });

    let auth = AuthResponse {
        machine_id: config.machine_id.clone(),
        challenge_id: challenge.challenge_id,
        signature: identity.sign(&nonce),
        rotation,
    };
    sink.send(Message::Text(
        ConnectionEnvelope::request(
            methods::AUTH_RESPONSE,
            serde_json::to_value(&auth).map_err(GatewayError::from)?,
        )
        .to_json()
        .into(),
    ))
    .await?;

    let accepted_env = read_envelope(&mut stream, config.handshake_timeout).await?;
    if accepted_env.message_type == MessageType::Error {
        let error = serde_json::from_value::<ApiError>(accepted_env.payload)
            .unwrap_or_else(|_| ApiError::new(error_codes::PAIRING_CODE_INVALID, "pairing failed"));
        return Err(error.into());
    }
    let accepted: ConnectionAccepted =
        serde_json::from_value(accepted_env.payload).map_err(GatewayError::from)?;
    let token = accepted
        .machine_token
        .ok_or_else(|| GatewayError::PairingCodeInvalid("server returned no token".into()))?;
    Ok(PairingResult {
        machine_id: accepted.machine_id,
        org_id: accepted.org_id,
        token,
    })
}
```

```rust
//! Pairing-code creation.

use chrono::Duration;
use fleet_core_auth::{generate_pair_code, hash_pair_code};
use fleet_core_common::{now, ApiError};
use fleet_core_protocol::authz::DEFAULT_ORG_ID;
use fleet_core_protocol::pairing::{CreatePairingCodeRequest, PairingCodeResponse};

use crate::error::AppError;
use crate::middleware::auth::Principal;
use crate::state::AppState;

pub struct PairingService;

impl PairingService {
    pub async fn create_code(
        state: &AppState,
        principal: &Principal,
        request: CreatePairingCodeRequest,
    ) -> Result<PairingCodeResponse, AppError> {
        let org_id = match principal.org_id() {
            Some(org) => {
                if let Some(requested) = request.org_id.as_deref() {
                    if requested != org {
                        return Err(AppError::new(
                            axum::http::StatusCode::FORBIDDEN,
                            fleet_core_common::error_codes::FORBIDDEN,
                            "cannot create pairing codes outside your organization",
                        ));
                    }
                }
                org.to_string()
            }
            None => request
                .org_id
                .clone()
                .unwrap_or_else(|| DEFAULT_ORG_ID.to_string()),
        };

        let organization = state
            .db
            .organizations
            .get(&org_id)
            .await?
            .ok_or_else(|| AppError::not_found(format!("organization {org_id} not found")))?;

        let code = generate_pair_code();
        let code_hash = hash_pair_code(&code).ok_or_else(|| {
            AppError::internal("generated pairing code failed validation")
        })?;
        let expires_at =
            now() + Duration::seconds(state.config.auth.pair_code_ttl_secs as i64);
        let id = state
            .db
            .pairing_codes
            .create(
                &organization.id,
                &principal.actor,
                request.machine_name.as_deref(),
                expires_at,
                &code_hash,
            )
            .await?;

        state
            .db
            .audit
            .append(
                &principal.actor,
                Some(&organization.id),
                "pairing.code.create",
                &id,
                serde_json::json!({"expires_at": expires_at}),
            )
            .await?;

        Ok(PairingCodeResponse {
            id,
            code,
            expires_at,
            org_id: organization.id,
        })
    }
}
```

```rust
impl MachineAuthenticator for RegistryAuthenticator {
    async fn machine_state(
        &self,
        machine_id: &str,
    ) -> Result<fleet_core_protocol::pairing::MachineAuthState, ApiError> {
        self.registry
            .storage()
            .machines
            .machine_state(machine_id)
            .await
            .map_err(storage_error)
    }

    async fn machine_for_token(&self, token: &str) -> Result<Option<String>, ApiError> {
        self.registry
            .storage()
            .machines
            .by_token_hash(&fleet_core_auth::hash_token(token))
            .await
            .map_err(storage_error)
    }

    async fn pairing_code(
        &self,
        code: &str,
    ) -> Result<fleet_core_protocol::pairing::PairingCodeStatus, ApiError> {
        let Some(hash) = fleet_core_auth::hash_pair_code(code) else {
            return Ok(fleet_core_protocol::pairing::PairingCodeStatus::Invalid);
        };
        self.registry
            .storage()
            .pairing_codes
            .lookup(&hash, self.max_attempts)
            .await
            .map_err(storage_error)
    }

    async fn record_pairing_failure(&self, code_id: &str) -> Result<(), ApiError> {
        self.registry
            .storage()
            .pairing_codes
            .record_failure(code_id)
            .await
            .map_err(storage_error)
    }

    async fn complete_pairing(
        &self,
        request: fleet_core_protocol::pairing::PairingCompletion,
    ) -> Result<fleet_core_protocol::pairing::PairingOutcome, ApiError> {
        self.registry
            .storage()
            .machines
            .complete_pairing(request, self.max_attempts)
            .await
    }

    // existing pin_key/is_revoked implementations stay
}
```

```rust
use std::path::PathBuf;

use fleet_core_auth::{
    load_or_create_machine_id, machine_token_path, save_machine_token, MachineIdentity,
};
use fleet_core_config::DaemonConfig;
use fleet_core_connection::{pair_machine, PairingConfig};
use fleet_core_protocol::PROTOCOL_VERSION;

pub async fn pair(
    config_path: Option<PathBuf>,
    server: String,
    code: String,
    name: Option<String>,
) -> anyhow::Result<()> {
    let mut config = DaemonConfig::load(config_path.as_deref())?;
    config.resolve_paths();

    let identity = MachineIdentity::load_or_create(&config.machine.key_file)?;
    let previous = MachineIdentity::load_previous(&config.machine.key_file)?;
    let machine_id = match config.machine.id.clone() {
        Some(id) => id,
        None => load_or_create_machine_id(&config.machine.key_file, &identity)?,
    };
    let machine_name = name
        .or_else(|| config.machine.name.clone())
        .unwrap_or_else(|| machine_id.clone());
    let hostname = std::env::var("HOSTNAME").unwrap_or_else(|_| "unknown".into());

    let result = pair_machine(
        PairingConfig {
            server_url: server,
            machine_id: machine_id.clone(),
            machine_name,
            hostname,
            os: std::env::consts::OS.to_string(),
            arch: std::env::consts::ARCH.to_string(),
            daemon_version: env!("CARGO_PKG_VERSION").into(),
            protocol_version: PROTOCOL_VERSION,
            pairing_code: code,
            handshake_timeout: std::time::Duration::from_secs(10),
        },
        &identity,
        previous.as_ref(),
    )
    .await?;

    let token_path = machine_token_path(&config.machine.key_file);
    save_machine_token(&token_path, &result.token)?;

    println!(
        "{}",
        serde_json::to_string_pretty(&serde_json::json!({
            "machine_id": result.machine_id,
            "org_id": result.org_id,
            "token_file": token_path,
        }))?
    );
    Ok(())
```

```rust
use std::path::{Path, PathBuf};

use anyhow::{bail, Context, Result};
use chrono::Duration;
use fleet_core_auth::{

use fleet_core_protocol::pairing::{CreatePairingCodeRequest, PairingCodeResponse};
use fleet_core_protocol::PROTOCOL_VERSION;

use crate::client::AdminClient;

use crate::output;

pub struct SetupOptions {
    pub admin_url: String,
    pub token: Option<String>,
    pub org_id: Option<String>,
    pub server_url: Option<String>,
    pub daemon_config: PathBuf,
    pub name: Option<String>,
    pub store_token: bool,
    pub allow_insecure: bool,
    pub configure_only: bool,

pub fn derive_ws_url(admin_url: &str) -> Result<String> {
    let admin_url = admin_url.trim().trim_end_matches('/');
    let ws = if let Some(rest) = admin_url.strip_prefix("https://") {
        format!("wss://{rest}")
    } else if let Some(rest) = admin_url.strip_prefix("http://") {
        format!("ws://{rest}")
    } else {
        bail!("admin URL must start with http:// or https://");
    };
    Ok(format!("{ws}/ws/machine"))
}

pub fn is_loopback(host: &str) -> bool {
    matches!(host, "localhost" | "127.0.0.1" | "::1" | "[::1]")
}

fn host_of(url: &str) -> Option<&str> {
    let rest = url
        .strip_prefix("ws://")
        .or_else(|| url.strip_prefix("http://"))?;
    Some(rest.split(['/', ':']).next().unwrap_or_default())
}

pub async fn setup(options: SetupOptions) -> Result<()> {
    let server_url = options
        .server_url
        .clone()
        .unwrap_or_else(|| derive_ws_url(&options.admin_url).unwrap_or_default());
    if server_url.starts_with("ws://") {
        if let Some(host) = host_of(&server_url) {
            if !is_loopback(host) && !options.allow_insecure {
                bail!("refusing plaintext ws:// to {host}; pass --allow-insecure on a trusted LAN");
            }
        }
    }

    let client = AdminClient::new(&options.admin_url, options.token.clone())?;
    client.health().await.context("agent admin is not reachable")?;

    let mut config = DaemonConfig::load(Some(&options.daemon_config))?;
    config.resolve_paths();
    let key_file = config.machine.key_file.clone();
    let identity = MachineIdentity::load_or_create(&key_file)?;
    let previous = MachineIdentity::load_previous(&key_file)?;
    let machine_id = match config.machine.id.clone() {
        Some(id) => id,
        None => load_or_create_machine_id(&key_file, &identity)?,
    };

    if !options.configure_only {
        let token = options.token.clone().context(
            "an admin token is required to create a pairing code; pass --token or set AGENT_FLEET_ADMIN_TOKEN",
        )?;
        let client = AdminClient::new(&options.admin_url, Some(token))?;
        let request = CreatePairingCodeRequest {
            org_id: options.org_id.clone(),
            machine_name: options.name.clone(),
        };
        let value = client
            .post("/api/v1/pairing/codes", serde_json::to_value(request)?)
            .await?;
        let code: PairingCodeResponse = serde_json::from_value(value)?;

        let result = pair_machine(
            PairingConfig {
                server_url: server_url.clone(),
                machine_id: machine_id.clone(),
                machine_name: options.name.clone().unwrap_or_else(|| machine_id.clone()),
                hostname: std::env::var("HOSTNAME").unwrap_or_else(|_| "unknown".into()),
                os: std::env::consts::OS.to_string(),
                arch: std::env::consts::ARCH.to_string(),
                daemon_version: env!("CARGO_PKG_VERSION").into(),
                protocol_version: PROTOCOL_VERSION,
                pairing_code: code.code,
                handshake_timeout: std::time::Duration::from_secs(10),
            },
            &identity,
            previous.as_ref(),
        )
        .await?;

        save_machine_token(&machine_token_path(&key_file), &result.token)?;
        println!(
            "paired machine {} into {}",
            result.machine_id,
            result.org_id.as_deref().unwrap_or("unknown")
        );
    }

    let mut edits = vec![TomlEdit {
        section: "connection",
        key: "server_url",
        value: server_url.clone(),
    }];
    edits.push(TomlEdit {
        section: "machine",
        key: "id",
        value: machine_id.clone(),
    });
    if let Some(name) = options.name.as_deref() {
        edits.push(TomlEdit {
            section: "machine",
            key: "name",
            value: name.to_string(),
        });
    }
    let backup = edit_toml(&options.daemon_config, &edits)?;
    remove_toml_keys(
        &options.daemon_config,
        &[("connection", "token"), ("connection", "pairing_code")],
    )?;

    if options.store_token {
        let mut cli = CliConfig::load(&crate::config::default_cli_config_path())?;
        cli.token = options.token.clone();
        cli.admin_url = Some(options.admin_url.clone());
        cli.save(&crate::config::default_cli_config_path())?;
    }

    println!("updated {}{}", options.daemon_config.display(), backup
        .map(|path| format!(" (backup: {})", path.display()))
        .unwrap_or_default());
    println!("next: start the daemon so it connects with its per-machine token");
    Ok(())
}

pub async fn create_code(
    client: &AdminClient,
    org_id: Option<String>,
    machine_name: Option<String>,
    json: bool,
) -> Result<()> {
    let value = client
        .post(
            "/api/v1/pairing/codes",
            serde_json::to_value(CreatePairingCodeRequest { org_id, machine_name })?,
        )
        .await?;
    let response: PairingCodeResponse = serde_json::from_value(value)?;
    if json {
        return output::print_json(&serde_json::to_value(&response)?);
    }
    println!("code      {}", response.code);
    println!("expires   {}", response.expires_at);
    println!("org       {}", response.org_id);
    println!("\nthis code is shown once; do not paste it into shell history");
    Ok(())
}
```

```rust
/// Remove `[section] key` entries, preserving comments and backing up first.
pub fn remove_toml_keys(path: &Path, keys: &[(&str, &str)]) -> Result<Option<PathBuf>> {
    let backup = if path.exists() {
        Some(backup_file(path)?)
    } else {
        None
    };
    let mut document = if path.exists() {
        fs::read_to_string(path)
            .with_context(|| format!("failed to read {}", path.display()))?
            .parse::<DocumentMut>()
            .with_context(|| format!("invalid TOML in {}", path.display()))?
    } else {
        DocumentMut::new()
    };
    for (section, key) in keys {
        if let Some(table) = document.get_mut(section).and_then(Item::as_table_mut) {
            table.remove(key);
        }
    }
    write_private(path, document.to_string().as_bytes())
        .with_context(|| format!("failed to write {}", path.display()))?;
    Ok(backup)
}

/// Expand a leading `~/` using the current user's home directory.
pub fn expand_tilde(path: PathBuf) -> PathBuf {
    let Some(text) = path.to_str() else {
        return path;
    };
    let Some(rest) = text.strip_prefix("~/") else {
        return path;
    };
    dirs::home_dir()
        .map(|home| home.join(rest))
        .unwrap_or(path)
}
```
