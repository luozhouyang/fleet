These guides assume Fleet is installed and at least one admin is running. Each
guide states its prerequisites, gives copy-pasteable steps, and ends with a
verification step.

For how the internals work, see [How it works](/how-it-works/). For exact flags
and fields, see [Reference](/reference/).
