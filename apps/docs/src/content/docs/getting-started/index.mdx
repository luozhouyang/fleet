Fleet runs as two processes. The **admin** serves the web UI and REST API; the
**daemon** runs on the machine that owns your code and connects out to the
admin. You can run both on one host to try Fleet, or install the admin on a
server and enroll one daemon per development machine.

Start with installation, then follow the quick start to pair a machine and open
your first session.
